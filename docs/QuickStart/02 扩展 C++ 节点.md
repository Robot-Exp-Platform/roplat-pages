# 扩展 C++ 节点

本页展示如何在 Rust roplat 系统中声明一个 C++ 节点。

## 1. 增加依赖

`Cargo.toml`：

```toml
[dependencies]
roplat = { path = "../roplat/roplat" }
roplat_cpp = { path = "../roplat/roplat_cpp" }
roplat_cpp_msg = { path = "../roplat/roplat_cpp_msg" }

[build-dependencies]
roplat_build = { path = "../roplat/roplat_build" }
```

## 2. 定义消息

`src/msg.rs`：

```rust
#[roplat::roplat_msg(version = 1)]
#[repr(C)]
#[derive(Copy, Clone, Debug)]
pub struct Packet {
    pub id: u64,
    pub value: f64,
}
```

`#[roplat_msg]` 会生成 C header、Python stub、schema 和跨语言 `TypeBinding`。

## 3. 声明 C++ puppet

`src/puppet.rs`：

```rust
use crate::msg::Packet;

#[roplat::node(
    lang = "cpp",
    input(input, Packet),
    output(output, Packet),
)]
pub struct CppForward {
    pub gain: f64,
}

impl CppForward {
    pub fn with_gain(gain: f64) -> Self {
        Self { gain, ..Default::default() }
    }
}
```

这个 Rust 结构体不是算法实现本身，而是 Rust 侧的类型声明和配置字段。

## 4. 配置 build.rs

`build.rs`：

```rust
use roplat_build::{BuildOrchestrator, NativeBackend, NativeBuildConfig};

fn main() {
    if std::env::var("ROPLAT_PHASE").as_deref() == Ok("EXTRACT") {
        return;
    }

    let backend = NativeBackend::from_env("ROPLAT_NATIVE_BACKEND")
        .unwrap_or(NativeBackend::Cc);

    let native = NativeBuildConfig::new()
        .backend(backend)
        .library_name("my_robot_cpp")
        .include_dir("cpp/src");

    BuildOrchestrator::new()
        .native_build(native)
        .build()
        .expect("roplat code generation failed");

    println!("cargo:rerun-if-changed=src/msg.rs");
    println!("cargo:rerun-if-changed=src/puppet.rs");
    println!("cargo:rerun-if-changed=cpp/src/");
    println!("cargo:rerun-if-changed=build.rs");
}
```

## 5. 生成用户文件

运行：

```powershell
cargo check
```

roplat 会生成：

```text
cpp/
  roplat_gen/        # generated, do not edit
  src/               # user C++ files
```

修改 `cpp/src/<node>.h` 中的用户类，实现 `process`。

## 6. 在系统里使用

```rust
mod msg;
mod nodes;
mod puppet;

#[roplat::system]
async fn main() {
    let mut source = nodes::Source::default();
    let mut cpp = puppet::CppForward::with_gain(2.0);
    let mut sink = nodes::Sink;
    let (_, mut timer) = roplat::rhythm::create_count_rhythm(1);

    timer >> {
        source >> cpp >> sink;
    };
}
```

## 常见问题

- 不要编辑 `cpp/roplat_gen`。
- C++ 用户文件只在缺失时生成；已有文件不会覆盖。
- 复杂 native 依赖用 `NativeBuildConfig::package`、`link_lib`、`include_dir`。
- 找不到 `roplat_cpp/include` 时再显式配置 `roplat_cpp_include`。
