# 实现数据互通

Roplat 有三类常见数据互通方式：

1. System DSL 中的普通节点边。
2. 透明或不透明跨语言消息。
3. Sideband / IPC 通道。

## 普通节点边

同一个 system 图里的普通数据流使用 `>>`：

```rust
timer >> {
    source >> filter >> sink;
};
```

这是默认选择。

## 透明消息

当 Rust、C++、Python 都可以共享固定内存布局时，使用透明消息：

```rust
#[roplat::roplat_msg(version = 1)]
#[repr(C)]
#[derive(Copy, Clone, Debug)]
pub struct Packet {
    pub id: u64,
    pub value: f64,
}
```

适合：

- 数值状态。
- 控制指令。
- 小型 fixed-layout 传感器消息。
- IPC payload。

避免：

- `Vec<T>`、`String` 等非固定布局。
- Python object、OpenCV Mat、C++ class 这类 native object。

## 不透明消息

当值应该留在 C++ 或 Python 侧时，使用 opaque：

```rust
#[roplat::roplat_msg(lang = "py")]
pub struct PyFrame {
    pub width: u32,
    pub height: u32,
}
```

opaque 的 Rust 类型主要是标记和绑定信息。具体对象由目标语言用户文件维护。

## Sideband

如果数据不属于普通图边，用 sideband。

最新状态：

```rust
let (publisher, subscribers) = roplat::comm::create_triple_buffer::<State>(2);
```

事件流：

```rust
let (writer, reader) = roplat::comm::create_ring_buffer::<Event>(128);
```

把这些 handle 放进节点字段或 launch resource，而不是替代所有 `>>` 边。

## IPC

跨进程时使用 IPC ring/triple buffer。消息应使用 `#[roplat_msg(version = N)]`，这样 schema id 和版本能参与握手。

诊断：

```powershell
cargo roplat ipc ls
cargo roplat ipc introspect "roplat-ipc://<namespace>/<name>?msg=<schema>&v=<version>"
```

## 选择表

| 需求 | 推荐 |
|---|---|
| 同一 system 内节点连接 | `>>` |
| Rust/C++/Python fixed-layout 数据 | `#[roplat_msg] #[repr(C)]` |
| Python/C++ native object | `#[roplat_msg(lang = "...")]` |
| 最新状态共享 | Triple buffer |
| 有序事件流 | Ring buffer |
| 跨进程 | IPC |
